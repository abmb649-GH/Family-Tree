# Our Family Tree

A private, interactive family tree — built to keep our family's history, photos, and
relationships in one place that's easy for everyone to browse.

## Live site

- **Family (view only):** https://abmb649-gh.github.io/Family-Tree/family.html
  This is the link to share with family — browsing only, nothing to edit or break.
- **Editor:** https://abmb649-gh.github.io/Family-Tree/
  Full editing access (add people, photos, fix relationships, publish changes). Keep this one to yourself.

## What's in this repository

| File / folder | What it is |
|---|---|
| `index.html` | The main app — the editor, used to add/update the tree |
| `family.html` | The read-only version shared with family |
| `data.json` | Everyone's names, dates, and relationships |
| `photos/` | Every photo, as individual files |
| `tree.jpg` | The original scanned family tree chart (shown in the "Full Tree" tab) |
| `cover.jpg` | The preview image shown when this link is shared in WhatsApp etc. |

## Making changes

Day-to-day edits (adding a person, adding photos, fixing a relationship) can be done
straight from the editor link above, on any device — tap **Setup** once to connect it
to this repository with a GitHub access token, then every **Save** publishes live for
everyone immediately.

## A note on backups

Every change ever published here is kept permanently in this repository's history
(click **"History"** on any file to see every past version) — so even if something
ever looks wrong, nothing is ever really lost.
